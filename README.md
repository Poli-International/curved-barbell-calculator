## 🎯 Overview

Find the correct curved barbell internal length for rook, daith, snug, conch, eyebrow, and navel piercings. Anatomy span + healing stage input.

**Category:** Piercing Science

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/) - a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **Curved Barbell Length**
- ✅ **Curved Barbell Size**
- ✅ **Rook Piercing Barbell Size**

- ✅ **Navel Barbell Length Calculator**
- ✅ **Body Jewelry Sizing**

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/curved-barbell-calculator/](https://poliinternational.com/tools/curved-barbell-calculator/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS - no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/curved-barbell-calculator.git
cd curved-barbell-calculator
# open index.html in your browser
```
